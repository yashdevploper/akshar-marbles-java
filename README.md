# Akshar Marbles

Monorepo for the Akshar Marbles static frontend and Java/Tomcat backend.

- `frontend/`: GitHub Pages site
- `backend/`: Maven WAR and Docker/Tomcat API service
- `database/`: MySQL/TiDB schema scripts
- `scripts/`: local build and run scripts
- `docs/`: deployment documentation

Set `frontend/assets/js/config/api-config.js` `RENDER_BASE_URL` to the deployed Render service URL.
